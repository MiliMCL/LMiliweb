核心特性

在 Folia 区域多线程调度模型之上，提供稳定性修复、性能优化与 API 扩展

⚙

Folia 稳定性修复

系统性排查并修复 Folia 区域线程模型下的并发问题与崩溃风险

  • Region Balancer 共享线程池动态负载均衡
  • 无锁滑动窗口统计区域 tick 耗时
  • Adaptive TPS 根据实时负载动态调整
  • 全局 UUID 注册中心防止任务 ID 碰撞
  • catch(Exception) → catch(Throwable) 全面加固
🐛

Bug 修复

大量针对 Folia 区域线程模型的修复，覆盖关键游戏行为

  • 玩家重生位置修正
  • 实体传送跨区/末影珍珠/维度切换竞态修复
  • 区域外寻路/拴绳/目标选择防护
  • POI 更新延迟、区块重载检测
  • RegionizedTaskQueue 并发引用修正
⚡

通用性能优化

来自 Gale / Lithium / Pufferfish / SparklyPaper / Kaiiju 等上游的通用优化

  • 噪声生成、AI 属性集合、大脑映射优化
  • 实体移动零位移跳过、canSee 检查优化
  • 区块加载查找削减、寻路区域限制
  • 网络与协议层优化、区块增量压缩
  • 村民 lobotomize（发呆）优化
🔌

API 扩展

在 Folia/Paper API 之上提供更多能力，方便插件开发者

  • Tick Regions API（区域查询/操作）
  • ReplayMod 摄影师实体 API
  • Bytebuf 自定义数据包读写 API
  • 实体传送异步事件
  • Waypoint 路径点追踪 API

线程安全加固

对全部 Java 源码进行系统性 bug 排查，覆盖致命级、资源泄漏级与并发竞态级问题

线程静默死亡修复
全项目 22+ 处 catch(Exception) → catch(Throwable)，防止 OOM/StackOverflow 等 Error 绕过捕获导致调度器线程永久死亡
致命级

致命级

writeIndex 溢出导致负索引 AIOOBE，改为 Math.floorMod
致命级
VillagerOptimizer 时间混淆
游戏世界时间与系统时间混存导致 elapsed 计算完全错误，已修正
致命级
RegionBalancer OOM
taskRecords 无限增长导致 OOM，已添加 TTL 清理
资源泄漏

旧条目失效时未关闭文件句柄，已添加 close() 调用
资源泄漏

快速开始

从源码构建 Mili 服务端核心

构建步骤
Gradle 依赖
Maven 依赖
环境要求：JDK 25+（Mili 26.2 分支需要 Java 25，不是 JDK 21）| Git 2.x（Windows 需启用长路径支持） 
# 1. 克隆仓库
git clone https://github.com/xucy10/Mili.git
cd Mili

# 2. Windows 需启用长路径
git config --global core.longpaths true

# 3. 应用补丁（首次构建必须执行）
./gradlew applyAllPatches --no-configuration-cache --no-build-cache

# 4. 注入 Kotlin 支持
python scripts/inject_kotlin.py

# 5. 构建 Paperclip JAR
./gradlew :mili-server:createPaperclipJar
构建产物：mili-server/build/libs/mili-26.2-paperclip.jar — 可直接运行的 Paperclip JAR 
repositories {
    maven {
        url = "https://repo.menthamc.org/repository/maven-public/"
    }

项目结构

模块化设计，职责清晰分离

Mili/
├── mili-api/                  # Mili API 模块
│   └── src/main/java/         #   事件 API、Photographer、Bytebuf
├── mili-server/               # Mili 服务端核心
│   ├── minecraft-patches/     #   97 个特征补丁（features/）
│   ├── paper-patches/         #   Paper API/Server 层补丁
│   └── src/main/
│       └── java/fun/bm/mili/  #   Java 源码
│           ├── bridge/        #     区块-区域桥接
│           ├── chunk/         #     区块系统
│           ├── command/       #     命令系统
│           ├── config/        #     配置模块（TOML，纯 Java 实现）
│           ├── metrics/       #     bStats 统计
│           ├── portal/        #     传送门管理
│           ├── utils/         #     工具类（区域调度、网络优化、内存管理等）
│           └── villager/      #     村民优化器
├── lmili-api/                 # LMili 附加 API 源（包名 fun.bm.mili.lmili）
├── folia-server/              # Folia 子模块（上游，不直接修改）
├── paper-server/              # Paper 服务器（补丁应用目标）
├── paper-api/                 # Paper API（补丁应用目标）
├── docs/                      # 文档
├── build.gradle.kts           # 根构建脚本
└── gradle.properties          # 版本与上游 ref 配置
