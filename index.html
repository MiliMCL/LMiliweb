Features

Why Mili?

在 Folia 区域多线程调度模型上构建的增强运行时

Rust Native Acceleration

通过 JNI 桥接的 Rust 原生库 (mili_optimizer) 加速高频计算路径。批量处理设计消除逐实体 JNI 开销，光照计算、遮挡剔除等热点路径直接在原生层完成。

TOML Config System

使用 Rust toml_edit 引擎替代 NightConfig，通过 JSON 批量传输在 JNI 边界高效传递配置数据。完整保留注释，支持热重载与递归删除。

Folia Region Balancer

共享线程池 + 优先级队列替代 Folia 的每区域独占线程。无锁滑动窗口统计 tick 耗时，根据实时负载动态分配 CPU 资源，低负载区域自动合并执行。

50+ Config Modules

覆盖实验性功能、漏洞修复、功能特性、协议兼容、杂项与性能优化六大类别。包括异步寻路、区块增量压缩、动态视距、实体密度热力图等高级选项。

Multiple Archive Formats

支持原版、Linear 和 b_linear 存档格式。MmapRegionStorage 提供内存映射加速的区域存储，ChunkDeltaCompression 减少网络带宽占用。

Redstone Enhancements

针对 Folia 区域调度的红石与生存电路兼容性增强。RedstoneDirtyTracking 优化红石更新追踪，RedstoneStats 提供统计分析，在多线程环境下更稳定。

TOML Engine

Rust toml_edit 替代 NightConfig 的 CommentedFileConfig。加载时将 TOML 解析为扁平化 JSON 传递给 Java，保存时接收 JSON 并写回带注释的 TOML。

pub fn load_config(path: &str) -> Option<String> { let content = fs::read_to_string(path).ok()?; parse_toml_to_json(&content) }

Batch JNI Design

Java 侧收集每帧数据到扁平数组，一次性传递给 Rust 处理并接收结果。消除逐实体 JNI 调用开销，光照计算和遮挡剔除在原生层并行完成。

// Java side: collect -> batch call -> receive results int[] result = RustBridge.processLightmap( flatLightData, width, height );

Cross-Platform

自动检测操作系统并加载对应的原生库：mili_optimizer.dll (Windows)、libmili_optimizer.so (Linux)、libmili_optimizer.dylib (macOS)。

// Extracted from JAR at runtime Path dst = tmp.resolve(lib); System.load(dst.toAbsolutePath().toString());

Quick Start

Get Started

从源码构建或直接下载预编译版本

1

Clone the repository

# Clone & enter git clone https://github.com/xucy10/Mili.git cd Mili
2

Apply patches

# Requires JDK 21+ and Rust toolchain # Windows: enable core.longpaths=true ./gradlew applyAllPatches --no-configuration-cache
3

Build the paperclip jar

# Inject Kotlin config & build python scripts/inject_kotlin.py ./gradlew :mili-server:createMojmapPaperclipJar
4

Find your jar

# Output location mili-server/build/libs/mili-paperclip-1.21.11-R0.1-SNAPSHOT-mojmap.jar
1

Download from GitHub Releases

Visit the Releases page and download the latest -mojmap.jar file.

2

Requirements

  • JDK 21 or higher
  • Minecraft 1.21.11
  • Recommended: 4+ CPU cores for Folia region threading
3

Run the server

java -jar mili-paperclip-1.21.11-R0.1-SNAPSHOT-mojmap.jar --nogui
