核心特性

为什么选择 Mili?

在 Folia 区域多线程调度模型上构建的增强运行时

Rust 原生加速

通过 JNI 桥接 Rust 原生库（mili_optimizer.dll/.so/.dylib），加速实体视锥剔除、TOML 配置读写等高频路径。零拷贝 DirectByteBuffer + Rayon 并行，每 tick 仅需 M 次 JNI 调用而非 N*M 次。缺失时自动回退纯 Java。

TOML 配置系统

使用 Rust toml_edit 引擎替代 NightConfig，完整保留注释，支持热重载与递归删除。JSON 批量传输在 JNI 边界高效传递配置数据，读写性能显著提升。

Folia 稳定性修复

Region Balancer 共享线程池 + 优先级队列替代每区域独占线程；无锁滑动窗口统计 tick 耗时；自适应 TPS 管理；跨区事件队列；全局 UUID 注册中心防碰撞；catch(Throwable) 加固防止 Error 导致调度器静默死亡。

红石与生电兼容

从 Leaves/Lophine 移植并适配 Folia 的全套红石修复：更新抑制（捕获异常防崩溃）、红石忽略向上更新、即时方块更新器、旧方块移除行为、羊毛漏斗计数器。生电机器安心运行，原版行为一个不少。

Carpet 与协议兼容

50+ 条 Carpet/TIS/AMS 规则映射，TPS/mobcaps/counter HUD 实时同步。TISCM、Jade、Syncmatica、Servux、XaeroMap、REI、BBOR、AppleSkin 等客户端 mod 协议全适配。

假玩家与摄影师

从 Leaves 移植的假玩家系统：创建/管理/移除假玩家，常驻、背包操作、动作执行（攻击、破坏、钓鱼、跳跃、移动等），配套完整 Java 事件 API。ReplayMod 摄影师实体录像，Photographer / PhotographerManager API。

实体视锥剔除

6 平面 AABB frustum 测试，Java 侧将实体数据打包进 DirectByteBuffer，Rust 通过 GetDirectBufferAddress 直接读取内存地址。每 tick 仅需 M 次 JNI 调用（M = 观察者数量），而非 N*M 次。

// Java: pack entities into buffer, one JNI call per observer var buf = ByteBuffer.allocateDirect(entities.size() * 32); for (var e : entities) { buf.putFloat(e.getX()); /* ... */ } int[] visible = RustBridge.cullEntities(buf, count, planes);

TOML 配置引擎

Rust toml_edit 替代 NightConfig。加载时将 TOML 解析为扁平化 JSON 传递给 Java，保存时接收 JSON 并写回带注释的 TOML。支持热重载与递归删除。

pub fn load_config(path: &str) -> Option<String> { let content = fs::read_to_string(path).ok()?; parse_toml_to_json(&content) }

跨平台原生库

自动检测操作系统并从 JAR 中释放对应的原生库：Windows .dll、Linux .so、macOS .dylib。缺失时自动回退纯 Java 实现。Rust 单独编译支持 cargo clippy（0 warning）与 cargo test（28 个单元测试）。

// Extract native lib from JAR at runtime Path dst = tmp.resolve(lib); Files.copy(jarEntry, dst, REPLACE_EXISTING); System.load(dst.toAbsolutePath().toString());

安全设计

⇾
catch_unwind 边界保护 所有 JNI 入口用 catch_unwind(AssertUnwindSafe(...)) 包装，防止 Rust panic 跨 JNI 边界传播至 Java 侧
⇾
#[unsafe(no_mangle)] 符合 Rust edition 2024 规范的导出符号声明，显式标注 unsafe 意图
⇾
overflow-checks=true Release 构建中开启算术溢出检查，防止整数溢出导致的未定义行为

快速上手

开始使用

从源码构建或直接下载预编译版本

1

克隆仓库

# Clone and enter directory git clone https://github.com/xucy10/Mili.git cd Mili
2

启用长路径（Windows）

# Windows only: enable long paths git config --global core.longpaths true
3

应用补丁

# Requires JDK 25+, Rust is optional ./gradlew applyAllPatches --no-configuration-cache --no-build-cache
4

注入 Kotlin 支持

# Inject Kotlin support (optional) python scripts/inject_kotlin.py
5

编译 Rust 原生库

# Compile Rust native lib (optional, falls back to Java) ./gradlew :mili-rust:stageRustBinary # Or build Rust independently: # cd mili-rust/src/rust && cargo build --release
6

构建 Paperclip JAR

# Build Paperclip JAR ./gradlew :mili-server:createMojmapPaperclipJar # Output: mili-server/build/libs/mili-paperclip-26.2-R0.1-SNAPSHOT.jar
1

从 GitHub Releases 下载

访问 Releases 页面，下载最新的 Paperclip JAR 文件。

2

环境要求

  • JDK 25 或更高版本（不是 JDK 21）
  • Minecraft 26.2
  • 推荐 4+ 核 CPU 以发挥 Folia 多线程优势
  • Rust stable (edition 2024) — 可选，用于编译原生优化库
3

启动服务器

java -jar mili-paperclip-26.2-R0.1-SNAPSHOT.jar --nogui
